# Branding

Logos, mascots, and visual identity for the Bestie language.
Mascot: **Finn the Dolphin** 🐬.

## Naming

| Use | Form |
| --- | ---- |
| Official / searchable name | **`bestielang`** |
| Friendly spoken & brand name | **Bestie** |
| Code namespaces, CLI, imports | `bestie` (e.g. `bestie.lib.collections`) |

The split mirrors *Golang* / *Go*: the bare word "bestie" is common in everyday English, so **`bestielang`** is the name to use for search, domains, repository topics, package registries, and hashtags (`#bestielang`), while **Bestie** is how you refer to the language in conversation and prose.

Always capitalize **Bestie** in prose; keep **`bestielang`** lowercase as an identifier.
